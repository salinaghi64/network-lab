

# Network Lab

A hands-on networking laboratory focused on learning, implementing, and troubleshooting fundamental network concepts.

## About This Repository

This repository contains practical networking scenarios and troubleshooting exercises developed as part of my ongoing learning journey in computer networking and CCNA preparation.

The main goal is not only to configure network devices, but also to understand how networks work and develop a structured approach to identifying and resolving connectivity problems.

- IPv4 Addressing
- Subnetting
- TCP/IP Fundamentals
- Ethernet and MAC Addressing
- ARP
- ICMP
- Routing Fundamentals
- Static Routing
- Default Gateway
- Routing Tables
- Ping and Traceroute
- Network Troubleshooting
- Cisco IOS Fundamentals

## Lab Environment

The scenarios in this repository are practiced using network simulation environments such as:

- Cisco Packet Tracer
- PNETLab

## Troubleshooting Approach

A major focus of this lab is developing a structured troubleshooting methodology.

For each problem, the troubleshooting process aims to follow a logical sequence:

1. Identify the problem
2. Understand the network topology
3. Check physical and Layer 2 connectivity
4. Verify IP addressing and subnet masks
5. Check default gateways
6. Verify ARP and MAC address information
7. Check routing tables
8. Test connectivity using Ping
9. Analyze the path using Traceroute
10. Identify and fix the root cause
11. Verify the solution

## Example Troubleshooting Scenarios

The lab focuses on practical scenarios involving problems such as:

- Incorrect IP addresses
- Incorrect subnet masks
- Incorrect default gateways
- Missing static routes
- Routing configuration errors
- Connectivity problems between different LANs
- Incorrect interface configuration
- Layer 2 and Layer 3 communication issues
